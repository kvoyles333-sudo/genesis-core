# Genesis Core

A decentralized cognition engine combining swarm intelligence, multi-dimensional tokenomics, and autonomous governance.

## System Architecture

Genesis Core is a production-grade implementation of:

- **Swarm Mesh Engine** - H3 Grid, Fibonacci Spiral, Consensus Rings
- **Multi-Dimensional Token Economy** - Upgrade Vectors [E, W, I, S, C]
- **Autonomous Governance** - AI-driven constitutional protocols
- **Idle Revenue Loops** - Self-sustaining economic flywheel
- **Cybernetic Feedback** - Observe → Analyze → Simulate → Optimize → Execute → Learn

## Quick Start

```bash
# Backend
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload

# Frontend
cd frontend
npm install
npm run dev

# Blockchain
cd contracts
forge build
forge test
```

## Directory Structure

```
genesis-core/
├── backend/              # FastAPI, Rust agents, orchestration
├── frontend/             # React Native, Next.js UI
├── contracts/            # Solidity smart contracts
├── core/                 # Shared types, utilities, math
├── agents/               # Swarm node implementations
├── indexers/             # The Graph, Kafka, real-time state
└── docs/                 # Architecture, formulas, governance
```
